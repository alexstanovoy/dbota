# Which Dota 2 name stands for which bota id. The `icon.*` and
# `sound.*` entries of manifest.txt are named after these Dota names.
#
#   item <item id> <dota item name>        icon.item.<name>    (panorama/images/items/<name>_png)
#   ability <ability id> <dota ability>    icon.ability.<name> (panorama/images/spellicons/<name>_png)
#   hero <hero id> <dota hero>             icon.hero.<name>, portrait.hero.<name>, minimap.hero.<name>
#   effect <effect id> <logical icon>      the icon Dota shows on the buff bar: an item's or an ability's
#   text <item|ability> <id> <dota key>    the Dota entry whose text describes it where that is not the
#                                          icon's name (an item is `item_<name>`)
#   modifier <effect id> <dota modifier>   the Dota modifier the effect is: its tooltip name and description
#                                          (`DOTA_Tooltip_<modifier>`) name the buff
#
# The files are Valve's: tools/import_assets.sh exports them into a local
# cache for personal use; they are never committed.
